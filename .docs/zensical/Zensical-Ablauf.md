## Aktivieren:

- **Linux / macOS / Code-Server:**

```bash
source .venv/bin/activate
```

---

## Projekt starten (Live-Vorschau)

```bash
zensical serve
```

💡 Wenn du im Code-Server bist und Port-Probleme hast:

```bash
zensical serve --host 0.0.0.0 --port 8080
```

---

## venv wieder deaktivieren

```bash
deactivate
```
